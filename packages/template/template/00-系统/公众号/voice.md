# 账号定位

- 平台：微信公众号（可同步 X 短帖）
- 方向：AI / 工程 / 开发者，重点是新范式、实践案例，以及 OpenAI、Anthropic/Claude、xAI/Grok、Google/Gemini 四家前沿厂商的动态
- 目标读者：一线工程师与开发者、技术负责人与 Tech Lead、AI 应用开发者、独立开发者
- 语气：专业、直白，不用没解释的黑话；有判断，但事实和观点要分开
- 代表作（3–5 篇链接或文件）：暂无，待补
- 禁用表达：营销腔、「颠覆」「炸裂」一类标题党、没有出处的数字
- 商业边界：不接软广与付费植入；不写无公开事实支撑的竞品对比

> 种子文件：创建知识库时从模板复制；可按账号自行修改。Agent 不得直写 `00-系统/`。
